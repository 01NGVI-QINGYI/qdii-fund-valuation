关于美股基金估值宝

天天基金自 2023 年起下线了官方盘中估值接口，本工具改用 定期报告持仓穿透 自行推算：取基金最新披露的前十大重仓股，逐一匹配 实时行情，再按权重还原成基金净值的估算涨跌。

估值口径

估算涨跌% = Σ(已交易持仓 wᵢ·pᵢ) × 股票占净比 / (Σw × 100)
  • 已交易：该标的在基金上次公布净值之后又交易过。尚未开盘的市场贡献为 0，不会高估。
  • 汇率：QDII 净值以人民币计价，美元 / 港币 / 日元资产按 (1+股价)(1+汇率)−1 折算，可开关。
  • 覆盖度：已交易重仓权重 ÷ 已知重仓权重，越高说明结果越完整。
  • 联接基金：直接持股为 0，敞口按「非现金资产」还原。
  • 覆盖市场：美股、港股、日股、沪 / 深 / 北交所。
  • 时段显示：盘前 / 盘中 / 盘后按美股时段划分，界面显示的时间段会自动换算到你当前的时区。

数据来源

  • 基金档案、净值走势、股票仓位 — 天天基金 pingzhongdata
  • 前十大重仓股 — 天天基金 FundArchivesDatas（季报口径）
  • 美 / 港 / 日 / A 股 / 指数实时行情 — 腾讯财经 qt.gtimg.cn
  • 行情与汇率备用源 — 新浪财经 hq.sinajs.cn；东方财富 push2delay 兜底

局限

  • 持仓来自季报，存在调仓滞后；报告期过旧的基金会明确标注。
  • 未覆盖的股票按已交易部分的参与度外推，可能偏离实际。
  • 部分联接基金上游未披露穿透持仓，这类基金无法估算，会明确说明。
  • 不含衍生品、打新、融券等收益。

本工具仅供学习与研究，所有数据与估算结果不构成任何投资建议。投资有风险，决策需谨慎。
